# Писатели и места Липецкого края

Справочный сайт о литературном краеведении Липецкой области: писатели, связанные с краем,
сохранившиеся памятные места, хронология событий и современная литературная жизнь.

Сайт собран из проверяемых фактов. У каждого утверждения есть источник, а там, где источники
расходятся, приведены обе версии — расхождения не сглажены и не «выбраны покрасивее».

## Как открыть

Сборка не нужна: ни пакетного менеджера, ни препроцессоров, ни фреймворков.

```bash
# вариант 1 — просто открыть файл
open index.html            # macOS
xdg-open index.html        # Linux

# вариант 2 — локальный статический сервер
python3 -m http.server 8000
# затем http://localhost:8000
```

Для публикации достаточно включить GitHub Pages на ветку с корневым каталогом `/ (root)`.

## Принципы

**Содержание**

- факт без источника на сайт не попадает; ссылки собраны в `istochniki.html`;
- противоречия между источниками приводятся явно («по одним данным… по другим…»);
- даты до февраля 1918 года даны по старому и новому стилю;
- цитаты публикуются только с подтверждённой атрибуцией — «вдохновляющих» цитат без источника
  на сайте нет;
- персоналии, по которым нет проверяемых сведений, вынесены в список «Ещё имена» без биографий;
- сведения о закрытии музеев (например, «Астапово» на реставрации до 31 августа 2027 года)
  вынесены в текст, а не в сноску.

**Оформление и код**

- внешних зависимостей нет: шрифты системные, иконочные библиотеки и CDN не подключены;
- светлая тема по умолчанию и тёмная — по системной настройке `prefers-color-scheme`;
- JavaScript не обязателен: панель фильтра скрыта атрибутом `hidden` и показывается скриптом,
  весь контент живёт в HTML;
- доступность: пропуск к содержанию, семантические разделы, `aria-current`, `aria-labelledby`,
  видимый фокус, подписи к таблицам;
- анимаций нет, `prefers-reduced-motion` отключает и плавную прокрутку;
- есть правила для печати: навигация скрывается, к внешним ссылкам добавляется адрес,
  записи не разрываются между страницами.

## История изменений

Первая версия проекта была одностраничной: весь HTML, CSS и JavaScript находились
в одном `index.html`, а данные о писателях — в массиве внутри скрипта. Часть биографических
сведений в ней не подтверждалась источниками (например, «ссылка Замятина в Липецке
в 1914—1917 годах» или работа Паустовского на липецком заводе), поэтому текст переписан
по краеведческим изданиям, а структура разделена на страницы и ассеты.

Прежняя версия доступна в истории Git:

```bash
git log --oneline -- index.html
git show 69954e1:index.html
```

## Как дополнить или сообщить об ошибке

1. Проверьте факт по независимому источнику — музейному сайту, библиотечному указателю,
   энциклопедии, архивному документу или областной прессе.
2. Добавьте источник в `istochniki.html` под следующим свободным номером.
3. Внесите правку в текст и поставьте надстрочную ссылку
   `<sup><a href="istochniki.html#sNN">NN</a></sup>`.
4. Обновите счётчики на главной странице и указатели, если добавилась запись.

Список вопросов, на которые пока нет надёжных ответов, — на странице
[«О проекте»](o-proekte.html#voprosy). Ошибку можно описать в
[issues репозитория](https://github.com/Luxius-developer/Lipetsk/issues): укажите факт,
источник и страницу.
