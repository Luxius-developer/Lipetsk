# Литературное наследие Липецкого края

Сайт, посвящённый литературному наследию Липецка и Липецкого края.

## О проекте

`index.html` — основной файл проекта, содержащий готовую веб-страницу о писателях и литературе Липецкого края. Страница выполнена как самостоятельный HTML-проект с CSS-оформлением и JavaScript-интерактивностью.

### Возможности страницы

- современный адаптивный дизайн;
- тёмная визуальная тема с неоновыми градиентами и эффектами свечения;
- карточки писателей и литературных деятелей;
- краткая информация о каждом авторе;
- интерактивные кнопки с дополнительными фактами и биографической информацией;
- всплывающие окна (модальные окна) с подробностями;
- генератор/переключатель литературных цитат;
- анимации появления элементов и интерактивные эффекты при наведении;
- поддержка мобильных устройств.

## Технологии

- **HTML5** — структура страницы;
- **CSS3** — оформление, адаптивность, анимации и визуальные эффекты;
- **JavaScript** — интерактивность страницы и модальные окна;
- **Font Awesome** — иконки;
- **Google Fonts** — шрифты Inter и Space Grotesk.

## Запуск

Проект не требует установки сервера или дополнительных зависимостей.

Просто откройте `index.html` в современном браузере.

Также проект можно разместить на **GitHub Pages** и использовать как обычный веб-сайт.
